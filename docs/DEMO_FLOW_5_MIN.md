# Demo flow — 3–5 minutes

## Goal

Show that the website is a **digital companion to the printed “Sổ tay hướng dẫn khởi nghiệp cùng Mầm”**, not a separate LMS.

## Before presenting

- Use one clean demo account.
- Keep the printed workbook available.
- Keep one QR/resource ready: `B06`.
- Keep one valid six-digit access code ready.
- Open the production domain before presenting.
- Do not expose real student reflections or private data.

## Suggested flow

### 0:00–0:30 — Home
Show:
- Mầm visual identity;
- current journey;
- 3-chapter structure;
- access-code entry.

Say in substance:
> The workbook is the main learning product. The website extends selected activities that benefit from interaction, media, progress tracking, or AI guidance.

### 0:30–1:10 — Workbook
Open the next lesson.

Show:
- chapter / lesson;
- short digital companion content;
- progress.

Avoid scrolling through every feature.

### 1:10–2:10 — QR / scenario
Use the printed QR or access code.

Show:
1. simulated situation;
2. optional student thought;
3. real case;
4. media if useful;
5. takeaway;
6. reflection.

Key point:
> The activity does not score a right/wrong answer. Students compare their first reaction with a real case and reflect.

### 2:10–3:15 — Contextual Mầm
Type a short reflection and select **Hỏi Mầm**.

Show:
- contextual banner;
- correct PsyCap focus;
- Mầm thinking state;
- concise response;
- one follow-up / one next action.

Key point:
> Mầm receives only the context needed for the current activity. It guides reflection rather than writing the student’s answer or assigning a PsyCap score.

### 3:15–3:45 — Progress
Briefly show:
- progress;
- XP/badge/streak if relevant.

Key point:
> Gamification visualizes the student’s own progress; it is not a public leaderboard.

### 3:45–4:30 — Close
Return to the workbook/home.

Close with:
> The system connects printed reflection with QR-triggered digital interaction, private progress, and contextual AI support while keeping the student as the decision-maker.

## Backup route if AI/network is slow

Do not spend the demo waiting.

Use:
1. Home
2. Workbook
3. QR scenario
4. show an already completed contextual Mầm conversation in the clean demo account
5. Progress

Keep screenshots of the production AI response only as an emergency backup for presentation equipment failure.
